OpenAPI

OpenAPI ist eine Spezifikation zum Erstellen von APIs, die Entwicklern ermöglicht, die Struktur ihrer APIs in einem standardisierten Format zu definieren.

https://www.openapis.org/

Funktionen

  • Standardisiertes Format: YAML oder JSON
  • Tool-Unterstützung: Codegenerierung, Dokumentation, Client-Bibliotheken
  • Einbindung in .NET mit ASP.NET sowie OpenAPI Bibliothek Swashbuckle

Beispiel Spezifikation
